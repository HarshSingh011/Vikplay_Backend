Real-time Video Streaming Platform

👋 Welcome to VikPay WebRTC Streaming!

This is a complete real-time video streaming solution using WebRTC technology. Choose your role below to get started.

🚀 Quick Start (3 Steps)

  1. Start the server - Make sure the FastAPI server is running on port 8000
  2. Broadcast - Open broadcaster.html to start streaming
  3. Watch - Open viewer.html to watch the stream
🎥
